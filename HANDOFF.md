## Invariants that are now enforced by `npm run verify`

A round of fixes removed a set of bugs that made parts of the site look
broken. Each one is now guarded by a test, so re-introducing it fails the
build rather than shipping. Do not "simplify" these away:

| Rule | Why it exists |
|---|---|
| `.reveal` hidden state must stay scoped to `html.js` | Unscoped, any JS failure left every animated section at `opacity:0` — the page rendered blank |
| `<head>` must keep the inline `document.documentElement.className="js"` | Sets the scope above before first paint, so content never flashes |
| CSS must keep `[hidden] { display: none !important }` | `.modal`, `.modal-scrim` and `.lb` set `display`, which beats the UA `[hidden]` rule — a "hidden" overlay stayed at `z-index:800` and ate every click |
| A `[data-rail]` scope must contain the `.rail` it scrolls | The arrows previously sat in their own scope, so `initRails` threw on `querySelector('')` and every carousel arrow on 12 pages was dead |
| Element ids must be unique | Three logos per page all declared `id="nxGold"` |
| The homepage must preload the image the hero actually paints, with `imagesrcset` | It preloaded `hero-1536.avif` (135 KB, high priority) which the walkthrough hero never renders |
| No bare `<img>` JPEG where AVIF/WebP exist | Derivatives were generated by `npm run images` and then never served |
| No handlers for markup no page renders | Dead `initTabs`/`initCopy`/`#leadBar` code |

## What this site is now

**Nexora Spaces LLP is a residential-only interior fit-out and design-build studio.**
Flats, apartments, villas, independent floors and individual rooms. No office, retail,
hospitality or commercial fit-out content anywhere.

## Two rules that must not regress

1. **No pricing, anywhere.** No rates, ranges, per-sq-ft figures, EMI, package prices,
   budget sliders or cost calculators — not in copy, not in JSON-LD, not in JS.
   Value is expressed in words only: "value-driven", "budget-smart luxury",
   "cost-effective".
2. **Residential only.** Every page speaks to homeowners.

Both are enforced automatically:

```bash
npm run build
npm run check     # links, images, canonicals, schema, headings
npm run verify    # the residential brief — fails on a pricing or commercial leak
```

## Deliberate decisions worth knowing

- **About Us is company-level only.** No team photos, no founder headshots, no
  "meet the team". The previous founder image and `assets/img/team/` were removed.
  `npm run verify` fails if portrait imagery returns.
- **Pricing pages are gone**, not hidden: `/pricing/`, `/cost-calculator/` and the whole
  `/commercial/` tree were deleted, and every inbound link was rewritten.
- **`richText()`** in `src/layouts/base.js` rewrites root-relative links inside authored
  FAQ/blog HTML through the deploy `basePath`. Without it, a hand-written
  `<a href="/warranty/">` in content data 404s on GitHub Project Pages.
